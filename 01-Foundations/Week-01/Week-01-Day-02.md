## Concepts learned
- The terminal uses my current working directory as the starting point for commands.
- Flags change the behavior of commands.
- The same flag can mean different things for different commands.
- The > symbol overwrites a file.
- The >> symbol appends to a file.
- The rm command deletes files and should be used carefully.
- grep searches inside files.
- find searches for files and folders.
- Git tracks changes, but only after I add and commit them.
